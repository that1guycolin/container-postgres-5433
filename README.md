# Postgres on 5433

The purpose of this repo is to provide a container image for postgres that runs
on port 5433 instead of the default 5432. It is heavily based on the [postgres
Docker library](https://github.com/docker-library/postgres). It's pretty much
entirely because I ran into a weird use case where I need two postgres
containers running.
